# ARHQ 实验结果汇总

## 实验配置

- **模型**: Qwen3-4B-Thinking-2507 (36 layers, hidden=2560, heads=32, kv_heads=8)
- **数据**: MATH-500 校准集, 50000 tokens per layer, 最后 2048 tokens 为评估集
- **量化**: NVFP4 E2M1, per-block(block_size=16) FP8 E4M3 scale
- **投影维度**: q_proj [4096,2560], k_proj [1024,2560], v_proj [1024,2560], o_proj [2560,4096]
- **指标**: 绝对 SNR (dB) = 20*log10(||Y_true|| / ||Y_hat - Y_true||), 越高越好

## 方法说明

| 缩写 | 含义 |
|------|------|
| SVDQuant | 截断 SVD: 在 W 上直接取前 r 个奇异方向 |
| ARHQ | Act-Residual Hessian: H_res = H + βR 加权的 SVD, H=A^TA/N, R=E^TE/N, E=A-Q(A) |
| smooth | SmoothQuant-style per-channel scaling: λ_i = max(\|X[:,i]\|)^α / max(\|W[i,:]\|)^(1-α), α per-layer 搜索 |
| raw | 不做 difficulty transfer |

## 1. 全 36 层 Sweep: raw 空间 ARHQ vs SVDQuant

不做任何 transfer, 直接比较两种低秩分解方式.

### 按 rank 平均 (144 个实验点 per rank)

| rank | SVDQuant avg imp | ARHQ avg imp | ARHQ 领先 | ARHQ 胜率 |
|------|-----------------|-------------|----------|----------|
| 32   | +1.21 dB        | +1.97 dB    | **+0.76 dB** | 81%  |
| 64   | +1.73 dB        | +2.82 dB    | **+1.09 dB** | 85%  |
| 128  | +2.56 dB        | +3.96 dB    | **+1.40 dB** | 95%  |
| 256  | +3.96 dB        | +5.65 dB    | **+1.70 dB** | 97%  |

### 按 proj 分解 (raw, rank=128, 36 层平均)

| proj    | SVDQuant | ARHQ   | ARHQ 领先 |
|---------|----------|--------|----------|
| q_proj  | +3.27    | +5.12  | **+1.86 dB** |
| k_proj  | +4.21    | +6.59  | **+2.37 dB** |
| v_proj  | +1.53    | +2.74  | **+1.21 dB** |
| o_proj  | +1.24    | +1.41  | **+0.17 dB** |

**结论**: raw 空间下 ARHQ 全面优于 SVDQuant, 优势在 q/k_proj 上最大.

## 关键发现

1. **ARHQ 在原始空间大幅优于 SVDQuant** (+0.76~1.70 dB), 因为量化误差有强方向性结构, H_res 能有效捕捉.

2. **Smoothing transfer 大幅提升 baseline** (~+0.5~1.0 dB), 且与 ARHQ 叠加后 smooth+ARHQ 是整体最优.

3. **默认 β 下 smooth+ARHQ 在 72%~78% 的情况下赢 smooth+SVDQuant**, 优势集中在 q/k_proj. 但 v/o_proj 上 SVDQuant 略好.

4. **增大 β 至 ×8~16 后, ARHQ 在所有 proj 上全面超过 SVDQuant**, 包括之前输的 v_proj 和 o_proj. 平均领先 +0.62 dB (smooth, rank=128). 推荐默认使用 β×16.

5. **β 收敛行为**: β×8 获得大部分收益, β×32 基本饱和. 默认公式 β = mean(diag(H))/mean(diag(R)) 低估了 R 的重要性.

6. **SmoothQuant scaling 没有像 Hadamard+ZCA 那样将量化误差完全均匀化**, 所以 ARHQ 的 H_res 仍然能提供有价值的方向信息.

7. **2D block weight 量化** 使整体 SNR 降低 ~1 dB, 但不改变方法间的相对排名.

8. **将 weight 量化残差纳入 H_res** 效果不稳定, 需要更好的融合策略.

## 6. H_res 成分消融: H_only vs H+R vs R_only

测试 H_res 中 H 和 R 各自的贡献, 9层, rank=128.

### 结果 (smooth setting, rank=128, 9层平均绝对 SNR dB)

| proj | SVDQuant | H_only | H+R β×1 | H+R β×4 | R_only |
|------|----------|--------|---------|---------|--------|
| q_proj | 27.04 | 26.44 | 27.45 | 27.65 | **27.73** |
| k_proj | 27.60 | 27.19 | 28.42 | 28.68 | **28.75** |
| v_proj | 21.01 | 20.59 | 21.20 | 21.38 | **21.48** |
| o_proj | 20.86 | 20.30 | 20.83 | 21.01 | **21.08** |

### 结果 (raw setting, rank=128, 9层平均绝对 SNR dB)

| proj | SVDQuant | H_only | H+R β×1 | H+R β×4 | R_only |
|------|----------|--------|---------|---------|--------|
| q_proj | 25.39 | 25.66 | 27.23 | 27.46 | **27.53** |
| k_proj | 25.94 | 26.45 | 28.20 | 28.47 | **28.54** |
| v_proj | 19.66 | 19.98 | 20.93 | 21.14 | **21.21** |
| o_proj | 20.09 | 19.81 | 20.41 | 20.58 | **20.62** |

### 排序一致性

两种 setting 下均有:

```
H_only < SVDQuant < H+R β×1 < H+R β×4 < R_only
```

### 分析

1. **H_only (只用 activation 二阶统计) 比 SVDQuant 差**. smooth 下全部 4 个 proj 均输.
   说明单纯按 activation 的协方差结构选子空间, 不如直接看 weight 的奇异值.

2. **R_only (只用量化残差协方差) 是所有配置中最好的**. 在两种 setting 下, 所有 proj 上均为最优.

3. **H 在 H_res 中的贡献为负**. 从 R_only 到 H+R β×4 到 H+R β×1, 随着 H 占比增大, SNR 逐步下降.
   H 不仅没帮忙, 反而稀释了 R 提供的量化误差方向信息.

4. **β sweep 的本质**: 之前观察到的 "β 越大越好" 现象, 本质上就是 H_res 从 H 主导逐渐过渡到 R 主导.
   当 β 足够大时 H_res ≈ β·R, 等价于 R_only.

### 结论

**ARHQ 的核心价值完全来自量化残差协方差 R = E^T E / N (其中 E = A - Q(A)), 而不是 activation Hessian H = A^T A / N.**

最简且最优的形式是直接用 R 做加权 SVD:

```
M = W @ R^{1/2}
SVD(M) → 取前 r 个方向 → 映回原坐标
```

不需要计算 H, 不需要 β 超参数.

---

## 更新后的关键发现

1. **R_only (只用量化残差协方差) 是最优配置**, 在所有 proj、所有 setting 上均为最好. 不需要 H, 不需要 β.

2. **H (activation Hessian) 对低秩子空间选择有负面影响**. H_only 甚至不如 SVDQuant. 这意味着 idea.md 中 "H 刻画输入方向重要性" 的直觉在本场景下不成立——重要的不是哪些方向被激活得多, 而是哪些方向最容易被量化器破坏.

3. **方法可以极大简化**: 最优流程为 SmoothQuant scaling + R-weighted SVD + NVFP4 量化残差. 无需计算 H, 无需调 β, 计算量更小.

4. **smooth + R_only 相对 smooth + SVDQuant 的优势** (rank=128, 9层平均):
   - q_proj: +0.69 dB
   - k_proj: +1.15 dB
   - v_proj: +0.47 dB
   - o_proj: +0.22 dB
   - 平均: +0.63 dB

5. **Smoothing transfer 仍然重要**. raw+R_only 虽然也很强, 但 smooth+R_only 在绝对 SNR 上更高 (smooth 提升了 baseline).

6. **2D block weight 量化** 使整体 SNR 降低 ~1 dB, 但不改变方法间的相对排名.

7. **将 weight 量化残差纳入 H_res** 效果不稳定, 不推荐.
